# まねっこ英語

小学生向けの英語発音まねっこゲームです。GitHub Pages で公開して、ブラウザのマイクを使って遊べます（学校のGoogle Apps Script教材ではマイクが使えないため、外部サイトとして作成しています）。

## 遊び方

1. スタートを押すと、英文が1つ出題されます（音声＋文字表示）。
2. 「きく」ボタンでお手本の発音をもう一度聞けます。
3. マイクボタンを押して、同じ文を声に出して真似します。
4. 発音が認識されて合っていればクリア、次の問題に進みます（1問につき2回まで挑戦可）。
5. **間違えたときは、「きこえた文」と「お手本の文」を単語ごとに色分け表示（緑＝言えていた／赤＝ちがっていた）し、発音のコツ（th・r・l・v・語尾のsなど）をヒント表示します。** ヒントを見てもう一度チャレンジできます。
6. 間違えるとゲーム終了。何問連続でクリアできたかがスコアになります。結果画面には最後にまちがえた問題の「きこえた文」「単語のちがい」「発音のコツ」がふりかえりとして表示され、その直下の「もういちど ちょうせん！」ボタンからすぐに再挑戦できます。
7. ゲーム終了時にかわいいランダムなプレイヤー名（形容詞×名詞、合計2,500通り）が自動でつけられ、ランキングに記録されます。
8. ランキングはブラウザ内（localStorage）に保存され、端末ごとに記録されます。ランキング画面を開いている間は5秒おきに自動で最新の状態に更新されます。

## 先生用：ランキングのリセット（ひみつコマンド）

児童が誤って操作できないよう、リセット用のボタンはあえて画面上に置いていません。ランキング画面を開いた状態でキーボードから

```
yorosikune3
```

と入力すると、ランキングがリセットされ「🔐 ランキングを リセットしました」と表示されます（クリック等は不要、そのままキー入力するだけです）。タブレット等キーボードのない端末では利用できないため、その場合はPCのブラウザで開くか、`script.js` 内の `SECRET_RESET_CODE` を確認のうえ操作してください。

- コードを変更したい場合は `script.js` の `SECRET_RESET_CODE`（定数）を書き換えてください。

## 使用技術

- 素のHTML / CSS / JavaScript（フレームワーク不要）
- 読み上げ：Web Speech API（`SpeechSynthesisUtterance`）
- 発話認識：Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`）
  - **対応ブラウザ：最新のGoogle Chrome（推奨）、Edge**。Safari/Firefoxは音声認識が未対応または不安定です。
  - マイク使用には **HTTPS** が必要です。GitHub Pagesは自動でHTTPS化されるため問題なく動作します。

## GitHubへの公開手順（GitHub Pages）

このフォルダには、すでに `git init` 済みのリポジトリが用意されています。以下の手順でご自身のGitHubアカウントに公開してください。

1. GitHubで新しいリポジトリを作成する（例：`manekko-eigo`）。README等は追加せず「空」のリポジトリで作成。
2. このフォルダでターミナルを開き、以下を実行：

   ```bash
   git remote add origin https://github.com/【あなたのユーザー名】/manekko-eigo.git
   git branch -M main
   git push -u origin main
   ```

3. GitHubのリポジトリページで **Settings → Pages** を開く。
4. 「Source」で `Deploy from a branch` を選び、Branch を `main` / `/(root)` にして Save。
5. 数分後、`https://【あなたのユーザー名】.github.io/manekko-eigo/` でアクセスできるようになります。
6. スマホ・タブレット・PCのChromeでアクセスし、マイクの使用を「許可」してください。

## ファイル構成

```
index.html     … 画面構造（タイトル／ゲーム／結果／ランキング）
style.css      … デザイン（子ども向けのポップな配色・アニメーション）
script.js      … ゲームロジック（出題・音声認識・採点・ランキング）
sentences.js   … 出題文リスト & ランキング用ランダム名パターン
```

## カスタマイズ

- **出題文を増やす／変える**：`sentences.js` の `SENTENCES` 配列に `{ en: "英文", jp: "日本語訳" }` を追加してください。
- **ランキングの名前パターンを増やす**：同じく `sentences.js` の `NAME_ADJECTIVES` / `NAME_NOUNS` を編集してください（掛け合わせでパターン数が決まります）。
- **判定の厳しさを調整**：`script.js` 内の `isMatch()` 関数のしきい値（`sim >= 0.72` など）を変更してください。
- **1問あたりの挑戦回数**：`script.js` の `MAX_ATTEMPTS_PER_QUESTION` を変更してください。
- **発音アドバイスの内容を変える**：`script.js` の `getPronunciationTip()` 関数を編集してください。

## 注意事項

- 音声認識の精度はブラウザ・マイクの性能に依存します。うまく認識されない場合は静かな環境で、はっきり発音するとよく認識されます。
- 発音アドバイスは、音声認識が聞き取った単語とお手本の単語を比較した簡易的なヒントです（発音そのものをAI判定しているわけではありません）。
- ランキングは端末（ブラウザ）ごとの保存です。全員で共通のランキングを共有したい場合は、Firebase等の外部データベースとの連携が別途必要です。

## トラブルシューティング

- `git commit` 実行時に `Unable to create '.git/index.lock': File exists` のようなエラーが出た場合は、以下を実行してから再度コミットしてください（前回のgit操作が異常終了した際の一時ファイルです）。

  ```bash
  rm -f .git/index.lock
  git add -A
  git commit -m "update"
  ```
